# Absensi-Sederhana
Sistem Absensi Sederhana adalah aplikasi berbasis web yang dikembangkan menggunakan PHP dan MySQL untuk memudahkan pengelolaan data karyawan serta pencatatan kehadiran secara digital. Aplikasi ini dirancang dengan antarmuka yang sederhana agar mudah digunakan untuk kebutuhan administrasi absensi karyawan.

🚀 Fitur Utama

Dashboard — Menampilkan halaman utama sistem.

Manajemen Data Karyawan — Mengelola data karyawan yang terdaftar dalam sistem.

Data Absensi — Melihat dan mengelola catatan kehadiran karyawan.

Check In — Mencatat waktu kedatangan karyawan.

Check Out — Mencatat waktu kepulangan karyawan.

Laporan Absensi — Menyediakan informasi kehadiran karyawan untuk kebutuhan pemantauan dan administrasi.
